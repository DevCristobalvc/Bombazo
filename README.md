# ⚽ BOMBAZO

Juego web arcade de **tandas de penales** estilo Copa Mundial FIFA 2026. Mobile-first, vertical, con todo el arte hecho en SVG.

> 📋 **Toda la especificación del juego está en [`idea.md`](./idea.md)** — concepto, mecánica de 9 zonas, IA por dificultad, dirección de arte, arquitectura y roadmap.

## Estado

🚧 **Fase 0** — Repositorio y especificación listos. El desarrollo del MVP (Fase 1) arranca en la próxima sesión.

## Stack (v1)

- HTML + CSS + JavaScript vanilla (sin build step)
- Arte 100% SVG propio
- Deploy: Vercel (sitio estático)

## Cómo correr (cuando exista el MVP)

Abrir `index.html` en el navegador, o servir con `npx serve .`
